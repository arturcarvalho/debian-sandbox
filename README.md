# proxmox

- On proxmox, using latest Debian ISO

## Initial steps

Clone repo:

```
git clone git@github.com:arturcarvalho/proxmox.git
```

## Next steps

- sudo tailscale up (auth)
- sign in: claude / codex

- review loop: roborev review --branch -> compact -> tui -> fix
